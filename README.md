# Undergraduate Management Module

## 📌 Overview

The Undergraduate Management Module is a part of the University Management System developed using Java. It focuses on managing undergraduate student information and academic records efficiently.

## ✨ Features

- View undergraduate details.
- Manage student academic information.
- View examination marks and grades.
- Check GPA and academic performance.
- View attendance records.
- Access medical records.
- View academic notices and timetables.

## 🛠️ Technologies Used

- Java
- MySQL / MariaDB
- JDBC
- JavaFX
