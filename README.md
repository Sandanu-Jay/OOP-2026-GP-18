# Faculty of Technology Management System 🎓

A Java and MySQL-based academic management system developed as part of the ICT2132 – Object Oriented Programming Practicum Mini Project at the University of Ruhuna, Faculty of Technology.

## 📌 Project Overview

The Faculty of Technology Management System is designed to manage academic and administrative activities through a centralized system. It supports user management, course details, undergraduate marks, attendance, medical records, notices, and timetables.

## ✨ Key Features

- 👤 **User Management** — Admin, Lecturer, Technical Officer, and Undergraduate profiles with role-based access.
- 📚 **Course Management** — Manage course details and learning materials.
- 📝 **Marks Management** — Record CA and final examination marks, view results, and check examination eligibility.
- 📊 **Attendance Management** — Track theory, practical, and combined attendance with batch and individual summaries.
- 🏥 **Medical Management** — Record medical submissions and track approval status.
- 🎓 **Academic Performance** — Calculate grades, SGPA, and CGPA according to the applicable grading criteria.
- 📢 **Notice Management** — Publish and view faculty notices.
- 🗓️ **Timetable Management** — Create, maintain, and view academic timetables.
- 🔐 **Role-Based Access** — Provide functionality according to each user's role.

## 👥 User Roles

| Role | Main Responsibilities |
|---|---|
| Admin | Manage users, courses, notices, and timetables |
| Lecturer | Manage course materials and marks; view student academic records |
| Technical Officer | Manage attendance and medical records |
| Undergraduate | View courses, attendance, medical records, results, and timetables; update permitted profile details |

## ⚙️ Setup and Installation

1. Install the Java Development Kit (JDK).
2. Install MySQL Server and a MySQL client such as MySQL Workbench.
3. Clone or download this repository.
4. Create the project database in MySQL.
5. Import the database schema and sample data provided in the repository.
6. Configure the database connection settings in the Java project.
7. Add the MySQL JDBC driver to the project.
8. Run the application's main Java class.
